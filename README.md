## About ToolPond

ToolPond brings a range of practical web tools together in one accessible collection. It includes calculators for mortgages, loans, salaries, calories, BMI, and currency conversion, along with generators for passwords, QR codes, and content calendars.

The project is intended for people who want to complete small calculations or generate useful outputs without installing a separate application for each task. It also includes browser games, making the site a mix of productivity utilities and lightweight web entertainment.

- Mortgage calculator for estimating home-loan figures
